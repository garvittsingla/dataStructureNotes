# 136. Single Number

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int ans = 0;
        for(int i = 0 ; i < nums.size();i++){
            ans ^= nums[i];
        }
        return ans;
    }
};
```
Performing a XOR operation with the number itself gives 0, so will just xor the number by itself and only the number which is single will be left
