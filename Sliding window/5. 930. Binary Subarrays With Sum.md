# LC. 930. Binary Subarrays With Sum

This question can be done with 2 ways

## Approach 1 : The same approach as subarray sum equals k, we, will calculate the sum and calculate the remaining sum that can be removed to get the goal. the number of subarrays can be determined by the number of times the remaider is occuring in the past.   
```cpp
class Solution {
public:
    int numSubarraysWithSum(vector<int>& nums, int goal) {
        int ans= 0;
        unordered_map<int,int> mpp; //to track the sum which happened the last time
        int sum = 0;
        for(int i = 0 ; i < nums.size();i++){
            sum += nums[i];
            if(goal == sum) ans++;
            int rem = sum - goal;
            if(mpp.count(rem)){
                ans += mpp[rem];
            }
            mpp[sum]++; //update the freq everytime , so that we can check 
            
        }
        return ans;
    }
};
```

## Approach 2 : vThe key insight — why atMost(goal) - atMost(goal-1)?
It's hard to count subarrays with sum exactly equal to goal directly, because your window can't stay fixed when sum equals goal — adding a 0 keeps it valid but changes nothing cleanly. So you use a trick:

exactly(goal) = atMost(goal) − atMost(goal − 1)

Think of it like a Venn diagram: atMost(2) gives all subarrays with sum 0, 1, or 2. atMost(1) gives all with sum 0 or 1. Subtracting cancels out the overlap, leaving only sum == 2.
How the helper (atMost) works:
The sliding window keeps sum ≤ goal. At each index i, the right pointer expands. If sum > goal, the left pointer shrinks — but only decrements sum when it skips a 1 (since only 1s contribute to the sum). Once the window is valid, (i - left + 1) counts all valid subarrays ending at i — that's the window of size i - left + 1.
The goal == 0 edge case:
When goal is 0, goal - 1 becomes -1, and atMost(-1) would incorrectly allow the while(sum > goal) loop to run forever (since any 1 would make sum = 1 > -1 and the loop never terminates cleanly). So the code short-circuits: if(goal == 0) return helper(nums, 0) — which directly returns atMost(0), which already equals exactly(0) since there are no subarrays with negative sums.


```cpp
class Solution {
public:
    int helper(vector<int> &nums,int goal){
        int ans = 0;
        int left = 0;
        int sum = 0;
        for(int i = 0 ; i < nums.size();i++){
            sum += nums[i];
            while(sum > goal){
                if(nums[left] == 1) sum--;
                left++;
            }
            ans += (i-left+1);
        }
        return ans;
    }
    int numSubarraysWithSum(vector<int>& nums, int goal) {
        if(goal == 0) return helper(nums, 0);
       return helper(nums,goal) - helper(nums,goal-1);
    }
};
```
