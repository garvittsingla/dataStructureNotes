## LC 3 Longest Substring Without Repeating Characters

Most standard question of string variable size window

## Approach
Update the frquency of current character in the map , if the freq of current character is more than we will shrink the window and then we recalculate the max length with a left pointer and the current index

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        int ans = 1;
        int left = 0;
        unordered_map<char,int> mpp; //track the window
        for(int i = 0 ; i < s.size();i++){
            mpp[s[i]]++;
            while(mpp[s[i]] > 1){
                mpp[s[left]]--;
                if(mpp[s[left]] == 0 ) mpp.erase(s[left]);
                left++;
            }
            ans = max(ans,i-left+1);
        }
        return ans;
    }
};
```
