# 78. Subsets
```cpp
class Solution {
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        int subsets = 1 << nums.size(); //n^2
        vector<vector<int>> ans;
        for(int i = 0 ; i < subsets  ; i++){
            vector<int> small;
            for(int j = 0 ; j < nums.size() ;j++){
                if((i & (1 << j))!=0){ //check if jth bit is on or off
                    small.push_back(nums[j]);
                }
            }
            ans.push_back(small);
        }
        return ans;
    }
};
```


Looping over the range of the subsets and then checking if the ith bit is set or not
