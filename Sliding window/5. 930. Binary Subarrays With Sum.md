# LC. 930. Binary Subarrays With Sum

This question can be done with 2 ways

## Approach 1 : The same approach as subarray sum equals k, we, will calculate the sum and calculate the remaining sum that can be removed to get the goal. the number of subarrays can be determined by the number of times the remaider is occuring in the past.   
```cpp
class Solution {
public:
    int numSubarraysWithSum(vector<int>& nums, int goal) {
        int ans= 0;
        unordered_map<int,int> mpp; //to track the sum which happened the last time
        int sum = 0;
        for(int i = 0 ; i < nums.size();i++){
            sum += nums[i];
            if(goal == sum) ans++;
            int rem = sum - goal;
            if(mpp.count(rem)){
                ans += mpp[rem];
            }
            mpp[sum]++; //update the freq everytime , so that we can check 
            
        }
        return ans;
    }
};
```
