# LC 904. Fruit Into Baskets

## Approach: Taking a map and updating the freq of element in it, shrinking the map until the map size is greater than 2 , and recalculating the max length again and again
```cpp
class Solution {
public:
    int totalFruit(vector<int>& nums) {
        int left = 0;
        unordered_map<int,int> mpp;
        int ans = 0;
        for(int i = 0 ; i < nums.size();i++){
            mpp[nums[i]]++;
            while(mpp.size()>2){
                mpp[nums[left]]--;
                if(mpp[nums[left]] == 0) mpp.erase(nums[left]);
                left++;
            }
            ans = max(ans,i-left+1);
        }
        return ans;
    }
};
```
