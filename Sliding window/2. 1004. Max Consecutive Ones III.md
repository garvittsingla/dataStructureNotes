# LC 1004. Max Consecutive Ones III

This question is a question , can be stated as max zeroes less than k , that can make a large sequence

## Approach : Tracking the number of zeroes till now, and shrinking the window untill number of zeroes are less than or queal to k and then calculating the max length by it.

```cpp
class Solution {
public:
    int longestOnes(vector<int>& nums, int k) {
        int left  = 0;
        int zeroes = 0;
        int ans = 0;
        for(int i = 0 ; i < nums.size();i++){
            if(nums[i]==0) zeroes++;
            while(zeroes > k){
                if(nums[left]==0) zeroes--;
                left++;
            }
            if(zeroes <= k) ans = max(ans,i-left+1);
        }
        return ans;
    }
};
```
