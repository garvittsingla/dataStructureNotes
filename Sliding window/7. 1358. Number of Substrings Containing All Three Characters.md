# LC 1358. Number of Substrings Containing All Three Characters

## Approach : Make a map of freq of 3 characters at a time,and calculate all the arrays from the end to this particular index
```cpp
class Solution {
public:
    int numberOfSubstrings(string s) {
        int ans = 0;
        int left = 0;
        vector<int> mpp(3,0);
        for(int i = 0 ; i < s.size() ; i++){
            mpp[s[i]-'a']++;
            while(mpp[0]>0 && mpp[1]>0 && mpp[2]>0){
                mpp[s[left]-'a']--;
                left++;
                ans += (s.size()-i);
            }
            
        }
        return ans;
    }
};
```
