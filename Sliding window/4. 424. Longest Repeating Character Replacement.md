# LC 424. Longest Repeating Character Replacement

## Approach : This is a difficult question, we can change any character other than the max frequency on to get the result , so will just keep a track of max frequency till now, then we can shrink the window if the freq of other elements is less than k and then we can recalculate the ans 
```cpp
class Solution {
public:
    int characterReplacement(string s, int k) {
        int ans = 0;
        int left = 0;
        int maxf = 0;
        unordered_map<char,int> mpp;
        for(int i = 0 ; i < s.size();i++){
            mpp[s[i]]++;
            maxf = max(maxf,mpp[s[i]]);

            //characters other than max frequency will be i - maxf
            while((i-left+1)-maxf > k){
                mpp[s[left]]--;
                if(mpp[s[left]] == 0) mpp.erase(s[left]);
                left++;
            }
            ans = max(ans,i-left+1);
        }
        return ans;
    }
};
```
