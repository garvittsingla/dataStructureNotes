# 137. Single Number II 
```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int ans = 0;
        for(int i = 0 ; i < 32 ; i++){ //ith bit is set or not
            int count = 0;
            for(auto num:nums){
                count += (num & (1 << i)) != 0 ? 1 : 0; //if ith bit is set
            }
            if(count!= 0 && count %3 == 1){ //set the ith bit
                ans = (ans | (1 << i)); 
            }
        }
        return ans;
    }
};
```

We check every ith bit wether it is set or not, if the ith bit is set we increase the count, since the number appears 3 times , there will be extra bit, in that case we will set that ith bit of the answer and make the final answer
