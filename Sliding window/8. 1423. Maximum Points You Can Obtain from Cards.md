# LC 1423. Maximum Points You Can Obtain from Cards

## Approach : First calculating the sum till k digits, and then removing that sum from starting and adding the last from last of the array. 

```cpp
class Solution {
public:
    int maxScore(vector<int>& nums, int k) {
        int sum = 0;
        for(int i = 0 ; i < k;i++){
            sum+=nums[i];
        }
        int ans = sum;
        for(int i = 0 ; i < k ; i++){
            sum -= nums[k-i-1];
            sum += nums[nums.size()-1-i];
            ans = max(ans,sum);
        }
        return ans;
    }
};
```
